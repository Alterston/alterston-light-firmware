# Alterston Light - готовые прошивки

Бесплатная прошивка и страница управления для самодельного аквариумного светильника на ESP32 (плата DemonMDV XEN-Controller LTRF и совместимые). Автор идеи: Антон Киршин.

- **Последняя версия:** 0.6.95 (2026-11-13) - [latest.json](latest.json)
- **Установка шнуром (с Xendil или на новую плату):** скачать [Alterston_Light_0.6.95_beta.zip](download/Alterston_Light_0.6.95_beta.zip), распаковать, запустить `1_USTANOVIT.bat`.
- **Обновление уже установленной Alterston Light:** по воздуху, страница светильника → «Информация» → «Обновление» (файл `fw/<версия>/alterston_light_<версия>_ota.bin`).

Каждая версия - в папке `fw/<версия>/`, контрольные суммы SHA-256 - в `latest.json`.
