# Alterston Light - готовые прошивки

Бесплатная прошивка и страница управления для самодельного аквариумного светильника на ESP32 (плата DemonMDV XEN-Controller LTRF и совместимые). Автор идеи: Антон Киршин.

- **Последняя версия:** 0.8.0 (2026-11-28) - [latest.json](latest.json)
- **Установка шнуром (с Xendil или на новую плату):** скачать [Alterston_Light_0.8.0_beta.zip](download/Alterston_Light_0.8.0_beta.zip), распаковать, запустить `1_USTANOVIT.bat`.
- **Обновление уже установленной Alterston Light:** по воздуху, страница светильника → «Информация» → «Обновление» (файл `fw/<версия>/alterston_light_<версия>_ota.bin`).

Каждая версия - в папке `fw/<версия>/`, контрольные суммы SHA-256 - в `latest.json`.

## Приложение для Android

- **Скачать:** [AlterstonLight_3.2.apk](https://alterston.github.io/alterston-light-firmware/app/AlterstonLight_3.2.apk) - бесплатно, Android 7.0 и новее; телефон и светильник в одной сети Wi-Fi.
- Приложения нет в Play Market: Android спросит разрешение ставить приложения из браузера. Play Защита может предложить проверить приложение: нажми «Проверить», версию 3.2 Google признал безопасной.
- Новые версии: в приложении «Ещё» → «Приложение» → «Скачать с сайта автора», открой скачанный файл и нажми «Установить». Настройки и список светильников сохранятся.
- **Качайте только отсюда.** Подлинное приложение подписано автором, отпечаток подписи SHA-256: `93:EA:2E:BA:52:38:F4:3D:68:54:13:4E:00:47:3F:F5:00:E9:46:32:A6:52:5D:F5:D4:36:2B:54:87:3A:71:34`. Приложение с другой подписью поверх подлинного не встанет.
