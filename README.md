# Alterston Light - готовые прошивки

Бесплатная прошивка и страница управления для самодельного аквариумного светильника на ESP32 (плата DemonMDV XEN-Controller LTRF и совместимые). Автор идеи: Антон Киршин.

- **Последняя версия:** 0.7.7 (2026-11-15) - [latest.json](latest.json)
- **Установка шнуром (с Xendil или на новую плату):** скачать [Alterston_Light_0.7.7_beta.zip](download/Alterston_Light_0.7.7_beta.zip), распаковать, запустить `1_USTANOVIT.bat`.
- **Обновление уже установленной Alterston Light:** по воздуху, страница светильника → «Информация» → «Обновление» (файл `fw/<версия>/alterston_light_<версия>_ota.bin`).

Каждая версия - в папке `fw/<версия>/`, контрольные суммы SHA-256 - в `latest.json`.

## Приложение для Android

- **Скачать:** [AlterstonLight_3.1.apk](app/AlterstonLight_3.1.apk) - бесплатно, Android 7.0 и новее; телефон и светильник в одной сети Wi-Fi.
- Приложения нет в Play Market: Android спросит разрешение ставить приложения из этого источника. Дальше приложение обновляется само с этого сайта («Ещё» → «Приложение»).
- **Качайте только отсюда.** Подлинное приложение подписано автором, отпечаток подписи SHA-256: `93:EA:2E:BA:52:38:F4:3D:68:54:13:4E:00:47:3F:F5:00:E9:46:32:A6:52:5D:F5:D4:36:2B:54:87:3A:71:34`. Приложение с другой подписью поверх подлинного не встанет.
